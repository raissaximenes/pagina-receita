# Página de Receita 

Este projeto é uma página simples de receita desenvolvida como exercício de HTML e CSS proposto pela Rocketseat. 

## Funcionalidades
- Lista de ingredientes
- Modo de preparo
- Layout organizado

## Tecnologias
- HTML5
- CSS3
- Figma

## Como visualizar
Abra o arquivo `index.html` no navegador.
